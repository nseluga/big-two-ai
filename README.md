# Big Two AI

A research-style reinforcement-learning project on **Big Two** (4-player imperfect-information shedding card game): a config-agnostic simulator (3–8 players, 1–2 decks, two rule variants), a DouZero-style Deep Monte-Carlo engine, a pre-registered strength ladder, a cross-play benchmark of existing public bots, and a pre-registered test of whether test-time belief-sampled search improves the learned policy.

Status: spec written, no code yet. Design docs are kept private for now.
